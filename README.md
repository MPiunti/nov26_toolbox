# nov26_toolbox
coding toolbox

## Skills

Assistant skills live under [`skills/`](skills/), one folder per skill (each with its own `SKILL.md`):

* [`skills/database_skill`](skills/database_skill/SKILL.md) — database schema conventions: declarative SQL, table/view creation scripts in `db_creation/`, commented fields, natural primary/foreign keys as explicit constraints, and key-integrity unit tests in `test/`.
* [`skills/coding_skill`](skills/coding_skill/SKILL.md) — PySpark / data engineering coding conventions: Spark-native transformations, composable pure helpers, Python conventions, and reusable `patterns/`.
